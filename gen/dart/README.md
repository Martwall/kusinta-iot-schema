# kusinta_iot_schema (Dart)

Generated protobuf types for the Kusinta building automation platform.

## Install

Add to your `pubspec.yaml`, pinned to a release tag:

```yaml
dependencies:
  kusinta_iot_schema:
    git:
      url: https://github.com/Martwall/kusinta-iot-schema.git
      ref: <TAG>
      path: gen/dart
```

## Usage

```dart
import 'package:kusinta_iot_schema/kusinta/iot/device/v1/device.pb.dart';
import 'package:kusinta_iot_schema/kusinta/iot/space/v1/space.pb.dart';
```
