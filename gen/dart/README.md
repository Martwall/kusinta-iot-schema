# kusinta_iot_schema (Dart)

Generated protobuf types for the Kusinta building automation platform.

## Install

Add to your `pubspec.yaml`, pinned to a release tag:

```yaml
dependencies:
  kusinta_iot_schema:
    git:
      url: https://github.com/Martwall/kusinta-iot-schema.git
      ref: <TAG>
      path: gen/dart
```

## Usage

Import the barrel for your leg:

```dart
import 'package:kusinta_iot_schema/app.dart';        // app ↔ gateway
import 'package:kusinta_iot_schema/connector.dart';  // connector ↔ gateway
```

Each barrel carries its own leg plus the leg-neutral domain types (device,
space, identity, access, common, registration, vendor).

**There is deliberately no single barrel over the whole package.**
`GatewayError` is declared on both legs — `connector.v1` and `webrtc.v1` — with
different authorization semantics, and Dart export directives cannot alias a
name, so no one library can surface both. Importing both barrels into the same
file hits the same ambiguity; import the generated files directly instead, or
prefix one:

```dart
import 'package:kusinta_iot_schema/connector.dart' as connector;
```

Direct imports work as well, and are the better choice when you need only a
type or two:

```dart
import 'package:kusinta_iot_schema/kusinta/iot/device/v1/device.pb.dart';
import 'package:kusinta_iot_schema/kusinta/iot/space/v1/space.pb.dart';
```

The barrels are generated by `gen-dart-barrels.py` at the repo root, run from
the CI Generate stage. Do not edit them by hand — a new proto reaches them
automatically, which the previous hand-written barrel did not.
